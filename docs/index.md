# Introdução

## Visão Geral
O objetivo deste projeto é construir um compilador da linguagem **Java** para a linguagem **C#**, atendendo aos requisitos da disciplina de **Compiladores 1**, ministrada pelo professor Dr. **Sergio Freitas** ([disponíveis neste repositório](https://github.com/sergioaafreitas/COMP1)). Por se tratar de um projeto com fins didáticos, o escopo será reduzido e não contemplará todos os recursos e paradigmas das linguagens originais, as decisões específicas de projeto podem ser encontradas na página [decisões de projeto](./decisoes.md).
