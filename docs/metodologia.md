# Metodologia

## Kanban

A equipe organiza o trabalho em um quadro Kanban no GitHub Projects, com cinco colunas:

- **Backlog**
- **In Progress**
- **In Review**
- **Done** 

Cada card representa uma tarefa de uma sprint (ver [Planejamento](./planejamento.md)),
com responsável e, quando aplicável, o link da issue/PR correspondente.

## Ritmo de sprints

- Sprints de 1 semana (26/Ago a 23/Set, 4 sprints no total até a Entrega 1).
- Daily via Whatsapp 
- Reunião semanal de acompanhamento: Quarta-feira (formato presencial).
- Decisões técnicas relevantes são registradas na página
  [Decisões de Projeto](./decisoes.md).

## Papéis por sprint
As tarefas são atribuidas de forma dinâmica, variando qual papel qual integrante vai assumir em cada sprint.
