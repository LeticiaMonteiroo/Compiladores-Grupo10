Escopo da Linguagem (Java → C#)

Este documento descreve o subconjunto que o compilador reconhece atualmente. O projeto gera C# para parte das construções suportadas, mas ainda não implementa uma tradução completa de Java. As decisões sobre o escopo estão em Decisões de Projeto.

Área Implementado
Tipos int, double, float, boolean, char, long, short, byte, String e void como tipo de retorno
Classe Uma classe por programa; modificador public opcional
Métodos Métodos com tipo de retorno e um modificador de acesso (public, private ou protected), com static opcional, ou somente static
Parâmetros Parâmetros posicionais com tipo e nome, separados por vírgula; representados na AST
Declarações locais Variáveis dos tipos listados, com ou sem inicialização
Atribuições Atribuição simples (=) e composta (+=, -=, *=, /=, %=)
Incremento/decremento Formas prefixas e pós-fixas (++ e --), como comandos ou fatores de expressão
Laços while com condição e bloco
Condicionais if com else opcional; a condição deve ser boolean e os corpos ficam entre chaves
Expressões Literais, identificadores, parênteses, operadores aritméticos, relacionais e lógicos
Comentários Comentários de linha (//) e de bloco (/* ... */), ignorados pelo lexer
AST Árvore sintática abstrata construída durante o parsing e impressa ao final
Tabela de símbolos Pilha de escopos (global, método e blocos de while, if e else); registra classe, métodos, parâmetros e variáveis; é impressa ao final, por escopo
Geração de C# Saída parcial para declarações locais, atribuições, while, if/else, operadores e comandos de impressão suportados

Fluxo do compilador

  1. Análise léxica — Flex (Projeto-Compilador/lexer/lexer.l): transforma caracteres em tokens, reconhecendo palavras-chave, identificadores, literais, operadores e delimitadores, e ignora espaços e comentários.
  2. Análise sintática — Bison (Projeto-Compilador/parser/parser.y): valida a sequência de tokens segundo a gramática e constrói a AST.
  3. AST e tabela de símbolos (src/ast.c, src/tabela_simbolos.c): a AST representa classes, métodos, comandos e expressões; a tabela registra símbolos nos escopos global, de método e de bloco (while, if e else).
  4. Análise semântica (src/semantico.c): verifica redeclarações, visibilidade e ordem de uso de variáveis, compatibilidade de tipos e condições booleanas de while e if.
  5. Geração de C# (src/codegen.c): após sucesso das análises, pode emitir C# para os nós de AST suportados quando um caminho de saída é fornecido. A saída não é executada pelo compilador.

Mapeamento de tipos e comandos

Tipo Java reconhecido Saída C#
boolean bool
String string
byte sbyte
short, int, long, float, double, char, void Mantido sem alteração

System.out.println é traduzido para Console.WriteLine, System.out.print para Console.Write e as formas reconhecidas de printf para Console.Write. Um método chamado main é emitido como public static void Main(string[] args). Os demais métodos são emitidos como public; os modificadores de acesso originais não são preservados.

Particularidades da tradução

  • Condicionais: if (cond) { ... } else { ... } é emitido com as chaves em linhas próprias, como nos demais blocos.
  • Variáveis de bloco com o mesmo nome: Java aceita declarar int x dentro de um bloco (while, if ou else) e outro int x depois dele, no bloco externo; C# rejeita isso (erro CS0136). O gerador renomeia a variável interna (x vira x_1) e todos os seus usos dentro do bloco.
  • Parênteses: a AST não guarda parênteses, então o gerador os reinsere conforme a precedência, inclusive à direita de operadores de mesma precedência ("x" + (1 + 2) não vira "x" + 1 + 2) e em sinais repetidos (-(-a), para não virar o decremento --a).
  • boolean em texto: o C# imprime True/False; para manter o Java (true/false), valores boolean impressos ou concatenados a texto são emitidos com .ToString().ToLower().
  • printf: o formato é convertido para o do C#: %d, %s, %c e %b viram {0}, {1}, ...; %f e %.2f viram {0:F6} e {0:F2}; %x e %X mantêm a caixa; largura (%5d, %-5d) vira {0,5} e {0,-5}; %n vira quebra de linha e %% vira %.
  • Caracteres e identificadores: escapes de char ('\n', '\'') são preservados; identificadores que são palavras reservadas do C# recebem @ (string vira @string) e $ é substituído por _S_.
  • Parâmetros de array: int[] v é emitido como int[] v.
  • Métodos sem return: como a gramática não tem return, todo método que não é void nem main termina com throw new NotImplementedException();, para que o C# gerado compile.
  • Erros léxicos: um caractere inválido é contado como erro e impede a geração, assim como erros sintáticos e semânticos.

Exemplo de tradução

Entrada (HelloWorld.java):

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Comando, executado na pasta Projeto-Compilador:

./compilador tests/validos/39_hello_world.java /tmp/HelloWorld.cs

Saída gerada:

using System;

class HelloWorld
{
    public static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}

Operadores aceitos na sintaxe

  • Aritméticos binários: +, -, *, /, %, com precedência usual entre adição/subtração e multiplicação/divisão/resto.
  • Aritméticos unários: + e -.
  • Relacionais: ==, !=, >, <, >=, <=.
  • Lógicos: &&, || e !.
  • Incremento e decremento: ++ e --, prefixos ou pós-fixos.
  • Atribuição: =, +=, -=, *=, /=, %= como comandos.

O lexer também reconhece operadores bit a bit (>>, <<, >>>, &, |, ^, ~), mas eles não são aceitos nas produções da gramática.

Limitações atuais

  • Geração de C#: cobre somente os nós de AST implementados e não garante uma tradução completa ou compilável para qualquer programa Java.
  • Chamadas de método: chamadas não fazem parte da gramática. Parâmetros são aceitos nas assinaturas e ficam no escopo do método.
  • Retorno de métodos: return é reconhecido pelo lexer, mas ainda não há produção sintática para ele.
  • Outras estruturas de controle: for, do-while e switch. No if, a gramática exige blocos entre chaves e o else aceita somente um bloco: else if e if/else sem chaves (corpo de um único comando) resultam em erro de sintaxe.
  • Expressões e comandos adicionais: arrays são aceitos somente como tipo de parâmetro; declarações e acesso a elementos, acesso a membros, chamadas, operadores bit a bit e atribuições dentro de expressões não são suportados.
  • Orientação a objetos completa: herança, interfaces, polimorfismo, construtores, atributos e múltiplas classes por arquivo.
  • Análise semântica: cobre redeclaração, escopo de variáveis (método e blocos de while, if e else), uso de identificadores e compatibilidade de tipos em declarações, atribuições e condições. Variáveis e parâmetros não podem sombrear outro nome local do mesmo método. Uma variável declarada dentro de um bloco não é visível fora dele, e os blocos then e else podem declarar o mesmo nome. Não há verificação de retorno nem de chamadas, pois essas construções não existem na gramática.

Exemplo de código aceito

public class Exemplo {
    public static void main() {
        int contador = 3;
        while (contador > 0) {
            contador -= 1;
        }
    }
}

O parser reconhece o exemplo, constrói a AST e a tabela de símbolos e imprime ambas. Também é possível solicitar a geração parcial de C# passando um caminho de saída ao executável; isso não significa que o programa gerado seja executado ou que todos os recursos de Java estejam traduzidos.

Exemplo com if/else

Entrada (Idade.java):

public class Idade {
    public static void main(String[] args) {
        int idade = 16;
        if (idade >= 18) {
            System.out.println("Maior de idade");
        } else {
            System.out.println("Menor de idade");
        }
    }
}

Saída gerada:

using System;

class Idade
{
    public static void Main(string[] args)
    {
        int idade = 16;
        if (idade >= 18)
        {
            Console.WriteLine("Maior de idade");
        }
        else
        {
            Console.WriteLine("Menor de idade");
        }
    }
}

Na AST impressa, o if aparece com os grupos Condicao, Entao e, quando existe, Senao; cada corpo é um nó Bloco.
